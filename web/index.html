What This Tool Does

This web application helps you design your energy system model and create PowerGenome settings files. It guides you through three key tasks:

  • Design your system: Define geographic regions, existing resources, and potential new-build technologies
  • Calculate interconnection costs: Automatically compute wind and solar interconnection costs based on your geographic setup
  • Export customizable settings: Generate a complete set of PowerGenome YAML files that you can further customize for your analysis

About Capacity Expansion Modeling

Capacity expansion models help answer questions like "What's the least-cost way to meet future electricity demand while meeting policy goals?" These models need several key inputs:

  • Geographic zones: Define regions with their hourly load, transmission constraints, existing resources, and renewable potential
  • Technology costs: Capital costs, fixed/variable O&M, heat rates, and financial parameters aligned to a consistent dollar-year
  • Fuel prices & emissions: Regional fuel costs and emissions factors for each planning period
  • Policy constraints: Renewable portfolio standards, clean energy standards, and emission limits

Existing Plants

📖 How to Use ▶ Show
  1. Group similar technologies: Check "Group similar technologies" to automatically group related tech types (e.g., Biomass). You can customize these groups using the editor below.
  2. Omit technologies: Use the dual-list to move technologies you want to exclude from clustering to the Omitted technologies column. "All Other", "Flywheel", and "Solar thermal" variants are omitted by default.
  3. Set cluster budget: Specify the total number of clusters across all technologies and regions. The default is set to 15% above the minimum required (one cluster per tech/region combination).
  4. Adjust thresholds: Modify Capacity Threshold (MW) and Heat-rate IQR Threshold to control when generators are suggested for splitting into multiple clusters.
  5. Run clustering: Click Run Plant Clustering to generate cluster assignments.
  6. Review suggestions: Check the "Top candidates for more splits" list to see which tech/region groups would benefit most from a higher budget.
💡 Tip: Plant clustering respects the model regions created in the Regions tab. If you haven't run region clustering yet, plants are grouped by their original BA.

ESR Policies (Optional)

📖 How to Use ▶ Show
  1. Overview: Energy Share Requirements (ESR) define minimum percentages of demand that must be met by qualifying resources in specific regions.
  2. RPS vs. CES: RPS (Renewable Portfolio Standard) requires renewable energy; CES (Clean Energy Standard) allows renewables plus nuclear and other clean technologies.
  3. Trading zones: The app automatically groups your model regions into trading zones based on state trading rules in rectable.csv. Each zone gets its own ESR constraints.
  4. Technology qualification: Technologies are matched against allowed_techs.csv to determine which can satisfy each ESR type.
  5. Optional step: If you do not need ESR policies, uncheck "Include ESR policies" and skip to Export.

Interconnection

Configure interconnection settings and generate resource group files.

Default Interconnection Cost

This default interconnection cost applies to resources like natural gas, batteries, or nuclear that don't have specific geospatial locations. Resources with specific locations (wind and solar) have their interconnection costs calculated dynamically based on how regions are aggregated. Learn more about advanced configuration →

Geospatial Resource Files

For wind and solar resources with specific geospatial locations and generation profiles, interconnection costs are calculated dynamically. These costs are included in parquet files along with an approximate LCOE (levelized cost of energy), which is based on ATB resource costs, interconnection costs, and average capacity factors. The parquet files and accompanying JSON files are referred to as "Resource Group" files. The LCOE values from these files are used in the "Renewables" tab for selecting the lowest-cost sites to include as resources in each model region.
